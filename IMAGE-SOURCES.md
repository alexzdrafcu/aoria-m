# Aoria image sources

All photography in `assets/images/` was selected for the Aoria static website mockup and downloaded from Unsplash on 2 August 2026. The photographs are used under the [Unsplash License](https://unsplash.com/license). Attribution is not required by that license, but creator credit and the original source page are included below as a courtesy and for provenance.

The selected set uses cinematic blues and teals, warm sunset light, earthy neutrals, strong negative space, and clear focal subjects. These qualities support the design brief's navy/ivory editorial palette, decisive crops, restrained overlays, and square/arch/full-bleed media treatments.

## Implementation notes

- Every file is stored locally; the HTML does not depend on temporary search-result or hotlink URLs.
- Images use `object-fit: cover` with page-specific focal positioning where needed and are never stretched.
- Below-the-fold images use native lazy loading.
- Informative photographs have descriptive alternative text in the HTML; purely decorative CSS shapes remain absent from the accessibility tree.
- The local files are resized source derivatives served at 1800–2000 pixels wide, suitable for desktop display and responsive CSS cropping.
